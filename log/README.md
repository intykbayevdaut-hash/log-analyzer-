# Лог анализ

Небольшой скрипт на Python, который читает лог-файл и показывает сводку: сколько в нём ошибок и предупреждений, какие ошибки повторяются чаще всего, с каких IP-адресов идёт больше всего запросов и в какие часы случалось больше всего сбоев.

Работает без сторонних библиотек, нужен только Python 3.8+.

## Запуск

```bash
python log_analyzer.py sample.log
```

Дополнительные параметры:

```bash
python log_analyzer.py sample.log --top 10      # показать топ-10 вместо топ-5
python log_analyzer.py sample.log --json        # вывод в JSON
cat sample.log | python log_analyzer.py -       # чтение из stdin
```

## Что показывает отчёт

- общее число строк и строк без уровня логирования;
- период, который покрывает лог;
- количество строк по уровням: DEBUG, INFO, WARNING, ERROR, CRITICAL;
- самые частые ошибки (похожие сообщения группируются: числа и IP заменяются на `<N>` и `<IP>`);
- самые частые IP-адреса;
- число ошибок по часам.

## Какие логи поддерживаются

Скрипт ищет в строках уровень (`INFO`, `ERROR` и т. д.) и время в формате `2026-10-14 09:01:12` или `2026-10-14T09:01:12`. Если в твоём логе другой формат, поправь регулярные выражения в начале `log_analyzer.py`.

## Идеи, как развивать проект

- фильтр по дате или уровню;
- вывод отчёта в HTML или CSV;
- поддержка других форматов времени (например, Apache и nginx);
- построение графиков.
